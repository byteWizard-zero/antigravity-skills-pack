# 🌌 Antigravity Skills & Plugins Suite

A curated, production-ready configuration pack for **Google Antigravity**, equipping coding agents with high-end UI design intelligence, the full GSAP animation engine, lean senior-dev code discipline, and battle-tested Vercel/React architectural patterns.

---

## ⚡ Quick Start (For Your Friend)

### 1. Clone this repository
```bash
git clone https://github.com/byteWizard-zero/antigravity-skills-pack.git
cd antigravity-skills-pack
```

### 2. Run the One-Click Installer

#### On Windows (PowerShell):
```powershell
powershell -ExecutionPolicy Bypass -File .\install.ps1
```

#### On macOS / Linux:
```bash
chmod +x ./install.sh
./install.sh
```

### 3. Restart Antigravity
Close and reopen Antigravity. All 32 skills, 7 plugins, and prompt rules will immediately be available to your agents!

## 🎨 Skills Overview

### 1. Motion & Animation (GSAP Suite)
- **`gsap-core`**: Core GSAP syntax, responsive animations with `gsap.matchMedia()`.
- **`gsap-timeline`**: Coordinated choreography and sequenced transitions.
- **`gsap-scrolltrigger`**: Parallax, scrubbing, and pinned reveals.
- **`gsap-react`**: Safe React integration using `@gsap/react` `useGSAP` with auto-cleanup.
- **`gsap-plugins`**: ScrollSmoother, Flip, Draggable, and SVG plugins.
- **`gsap-performance`**: 60fps hardware acceleration guidelines.

### 2. High-End UI & Anti-Slop
- **`impeccable`**: Spacing rhythm, visual hierarchy, micro-interactions.
- **`taste-skill`**: Prevents AI-generated template look on landing pages and apps.
- **`high-end-visual-design`**: Luxury digital agency aesthetics.
- **`minimalist-ui`** & **`industrial-brutalist-ui`**: Distinct editorial design philosophies.

### 3. Frontend Architecture & React
- **`react-best-practices`**: Next.js & React performance optimization from Vercel.
- **`composition-patterns`**: Reusable component APIs and React 19 patterns.
- **`react-view-transitions`**: Native browser view transitions.
